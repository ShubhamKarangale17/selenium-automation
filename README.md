# Selenium Automation Framework (Java)

This project is a Selenium Automation practice framework built using **Java** and **Page Object Model (POM)** principles.  
It demonstrates real-world automation structure and best practices for UI testing.

---

## 🔧 Tech Stack
- Java
- Selenium WebDriver
- Eclipse IDE
- Git & GitHub
- Page Object Model (POM)

## 🧠 Framework Design
- **BaseTest**  
  Handles browser setup and teardown logic.
- **Page Classes**  
  Contain element locators and page actions.
- **Test Classes**  
  Execute test scenarios using reusable page methods.
